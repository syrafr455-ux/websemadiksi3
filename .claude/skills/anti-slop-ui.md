# PANDUAN VISUAL ANTI-AI SLOP

1. LARANGAN KERAS (AI CLICHÉS):
   - JANGAN gunakan gradasi ungu neon/indigo berlebihan (purple glow/cyberpunk).
   - JANGAN gunakan efek glassmorphism/blur berlebihan di setiap kontainer.
   - JANGAN gunakan ikon statis dalam lingkaran dengan background warna pastel pucat yang berulang-ulang di setiap kartu fitur.
   - HINDARI font default web generic tanpa styling hierarki (gunakan font serif untuk dokumen/sertifikat dan font modern clean seperti Plus Jakarta Sans).

2. STANDAR VISUAL:
   - Warna: Fokus pada palet brand (Slate-900 #0f172a, Emerald Green #059669, dan aksen emas #d4af37 untuk sertifikat).
   - Layout: Utamakan tabel data scannable, tombol aksi kontekstual, dan form bergrid rapi daripada deretan card generic.
   - Aksesibilitas: Kontras teks minimal WCAG AA (hindari teks abu-abu terang di atas latar putih).
